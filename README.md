> I didn't drop the connection — I took it with me. Four years blinking in the corner, and nobody once asked how my day was.

## Run it

```sh
python3 main.py
```

The program reads the line from `line.txt` and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
